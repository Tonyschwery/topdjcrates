## What's the real difference between a clean edit and a radio edit?

They get used interchangeably, but they're not the same thing:

- **Clean edit** — profanity removed or swapped, often with a vocal drop-out or a re-sung line. Meaning stays intact.
- **Radio edit** — shortened AND cleaned, built for broadcast length, usually missing a verse or bridge.
- **Quick edit** — full-length but trimmed intros/outros so you can mix faster without losing energy.

A seasoned DJ prep workflow treats these as three separate tools. Ceremony and cocktail hour can usually run full-length originals. Reception needs quick edits to keep the floor moving. Corporate and brand events need **clean only, no exceptions** — a stray explicit word during a keynote after-party is the kind of mistake that ends a vendor relationship, not just a set.

## How to build a bulletproof clean-edit crate

1. **Tag everything at the file level.** Add "Clean" or "Explicit" directly into the file name and the metadata comment field, not just the folder name — Rekordbox and Serato search both.
2. **Build parallel smart crates.** One crate per genre, split into Clean and Explicit sub-crates, so a search for "Amapiano" never surfaces the wrong version by accident.
3. **Set hot cues on the drop, not just the intro.** For clean edits where a bar gets cut, you need a cue point that lands you back on beat instantly.
4. **Download both versions of every track you plan to play live.** If a client changes the vibe mid-event, you want the explicit version one pad hit away, not a re-download on venue Wi-Fi.
5. **Audition new packs in full before a gig, not during one.** New WAV downloads should get a clean/explicit pass the same day you buy them, while the track is fresh.
6. **Keep a dedicated "corporate-safe" playlist** that only contains verified clean content, so you're never guessing on-site.
